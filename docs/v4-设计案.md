## 任务三：战斗重构（重点，大巴扎式自动战斗）

**总原则**：玩家只负责**排兵布阵**，开战后**自动攻击**；英雄按速度/技能/攻击自动行动。

### 3.1 布阵阶段
- 每场战斗开始：从卡包随机抽 **9 张候选**，玩家用**布阵点（天机）**把英雄摆进 **5×3 九宫格**（最多 15 格、空位虚线）。
- **布阵点**：初始 **3 点**；顶级 **6 点**；装备法宝后可到 **9 点**。
- **布阵消耗按稀有度**：灰=1 / 绿=2 / 蓝=3 / 金=4 点。
- 三排语义（v3.10 已实现，无需改）：**上=近战 ⚔️ / 中=远程 🏹 / 下=谋略 🪶**（敌军垂直镜像：上谋略/中远程/下近战，同部门隔界河相对）。
- 点「开战」→ 进入自动战斗。

### 3.2 九宫格格子加成
- 每格有属性加成：**攻击+X% / 倍率×Y / 防御+Z**。
- **每场战斗开始时 15 格随机分配**加成；**基础档：攻击+10% / 倍率×2 / 防御+10%**。
- 「买地块」：后续版本在地图/商店购买地块升级某排/某列的加成（🔶待确认购买入口与价格）。
- **邻位光环**：部分英雄影响**左右相邻格**的英雄（+攻击/+防御），光环持续生效（🔶待确认具体英雄与数值，默认：金色英雄楚烈=左右+10% 攻击）。

### 3.3 自动战斗规则
- **回合** = 所有存活单位按**速度从高到低**行动一轮。
- **近战（战斗类）**：普攻同列最近的敌人（五行克制 ×1.3/×0.7，暴击 10%）。
- **远程（护卫类）**：普攻同列任意敌人（射程内，默认不打最前排优先打后排）。
- **谋略（计谋类）**：自动释放技能（带冷却，如每 2 回合一次），效果=现有招式卡效果（伤害/减益/增益）。
- 主将不参与九宫格（仍是"你"，被打的对象？——🔶待确认：主将血量在自动战斗中的角色，默认=若九宫格全灭则主将受攻击，主将死=输）。

### 3.4 卦象（3/5 主动选，7 天命自动）
- **第 3 回合：抽下卦 → 弹窗 3 选 1（主动选择）**。
- **第 5 回合：抽上卦 → 弹窗 3 选 1（主动选择）**。
- 第 7 回合：天命（64 卦）自动合成生效（不选）。

### 3.5 测试场景
- **从第一关打流寇开始**：流寇教学战（主角 + 阿大/阿二/阿三，灰绿英雄），复用 v3.10 教学流程。

## 任务四：稀有度 + 战时等级

### 4.1 稀有度（灰/绿/蓝/金）
- **灰色**：村民阿大/阿二/阿三（开局好友）。
- **绿色**：12 名初始老英雄。
- **蓝色**：3 新英雄（开山斧·雷震 / 铁壁·庞磐 / 点星笔·文若）+ 白泽·玄机。
- **金色**：专属金将（demo 通关奖励 + 招募 0.1% + 随机事件金将挑战）。
- 卡框颜色区分（灰/绿/蓝/金渐变描边）。
- **候选池门控**：普通战役只出灰/绿；**boss 战可选蓝将**；金将=招募所 0.1% 概率 / 随机事件「金将挑战」（打败金将获得）/ demo 通关奖励。

### 4.2 战时等级（两档）
- 营帐/事件触发升级：**黑杀 → 黑杀+（攻击 +15%）→ 黑杀++（+30%）**；本局内有效。
- 升到哪档在英雄名后显示 `+` / `++`。

### 5.1 地图结构（两条线 + 交汇点 🔶待确认节点细节）
```
                    ┌── 线A（善线）──────────────────┐
起点(王下村) ── 分叉 ┤ 战斗(流寇教学) → 营帐(回满+战时升级) → 好庄园主(+善+金)  ├── 交汇点 → Boss战(可选蓝将) → 通关奖励
```

- 打完通关 → 开启下一轮（层 +1，善恶继续累计）。
