## 任务三：战斗重构（重点，大巴扎式自动战斗）

**总原则**：玩家只负责**排兵布阵**，开战后**自动攻击**；英雄按速度/技能/攻击自动行动。

### 3.1 布阵阶段
- 每场战斗开始：从卡包随机抽 **9 张候选**，玩家用**布阵点（天机）**把英雄摆进 **5×3 九宫格**（最多 15 格、空位虚线）。
- **布阵点**：初始 **3 点**；顶级 **6 点**；装备法宝后可到 **9 点**。
- **布阵消耗按稀有度**：灰=1 / 绿=2 / 蓝=3 / 金=4 点。
- 三排语义（v3.10 已实现，无需改）：**上=近战 ⚔️ / 中=远程 🏹 / 下=谋略 🪶**（敌军垂直镜像：上谋略/中远程/下近战，同部门隔界河相对）。
- 点「开战」→ 进入自动战斗。

### 3.2 九宫格格子加成
- 每格有属性加成：**攻击+X% / 倍率×Y / 防御+Z**。
- **每场战斗开始时 15 格随机分配**加成；**基础档：攻击+10% / 倍率×2 / 防御+10%**。
- 「买地块」：后续版本在地图/商店购买地块升级某排/某列的加成（🔶待确认购买入口与价格）。
- **邻位光环**：部分英雄影响**左右相邻格**的英雄（+攻击/+防御），光环持续生效（🔶待确认具体英雄与数值，默认：金色英雄楚烈=左右+10% 攻击）。

### 3.3 自动战斗规则
- **回合** = 所有存活单位按**速度从高到低**行动一轮。
- **近战（战斗类）**：普攻同列最近的敌人（五行克制 ×1.3/×0.7，暴击 10%）。
- **远程（护卫类）**：普攻同列任意敌人（射程内，默认不打最前排优先打后排）。
- **谋略（计谋类）**：自动释放技能（带冷却，如每 2 回合一次），效果=现有招式卡效果（伤害/减益/增益）。
- **主将可上场布阵**（✅已确认）：主将占用布阵点，作为单位进九宫格；主将阵亡=输；主将天赋/法宝仍生效。

### 3.4 卦象（3/5 主动选，7 天命自动）
- **第 3 回合：抽下卦 → 弹窗 3 选 1（主动选择）**。
- **第 5 回合：抽上卦 → 弹窗 3 选 1（主动选择）**。
- 第 7 回合：天命（64 卦）自动合成生效（不选）。

### 3.5 测试场景
- **从第一关打流寇开始**：流寇教学战（主角 + 阿大/阿二/阿三，灰绿英雄），复用 v3.10 教学流程。

## 任务四：稀有度 + 战时等级

### 4.1 稀有度（灰/绿/蓝/金）
- **灰色**：村民阿大/阿二/阿三（开局好友）。
- **绿色**：12 名初始老英雄。
- **蓝色**：3 新英雄（开山斧·雷震 / 铁壁·庞磐 / 点星笔·文若）+ 白泽·玄机。
- **金色**：专属金将（demo 通关奖励 + 招募 0.1% + 随机事件金将挑战）。
- 卡框颜色区分（灰/绿/蓝/金渐变描边）。
- **候选池门控**：普通战役只出灰/绿；**boss 战可选蓝将**；金将=招募所 0.1% 概率 / 随机事件「金将挑战」（打败金将获得）/ demo 通关奖励。

### 4.2 战时等级（两档）
- 营帐/事件触发升级：**黑杀 → 黑杀+（攻击 +15%）→ 黑杀++（+30%）**；本局内有效。
- 升到哪档在英雄名后显示 `+` / `++`。

## demo 主线战场（火·炎漠 · 雇佣兵任务）

### 5.1 地图结构（Y 型 ✅已确认）
```
起点(雇佣军营帐) → 前置节点1 → 前置节点2 → 第3节点帐篷(交汇·善恶选择点)
    ├── 善线：好庄园主(+善+金) → Boss战(善·山河盟主)
    └── 恶线：坏官吏(+恶+军粮) → Boss战(恶·曜魔宗主)
```
- 流寇战 = 新手教学（新手战场），之后走剧情到第一战场；第一战场从雇佣军营帐出发。
- 两条线在第 3 节点以帐篷为交汇处，**在交汇点选择走善恶哪条路**，然后各自发散到各自的 Boss 战。
- 好事 +善 / 坏事 +恶；每完成一次战斗：金币（马蹄金）奖励。
- 营帐：恢复主将状态 + 增加英雄战时等级。
- **通关奖励**：军粮 + 马蹄金 + 金将（佣兵王·楚烈）+ 法宝 → 开启下一轮（层 +1）。
- **地图只设置出发点**（demo 只画这条线 + 出发点）。

### 5.2 金将：佣兵王·楚烈（✅已确认）
- 定位：金色 · 战斗 · 近战 · 攻 22 / 主将血 60（原血 15 × 4）· 速度 6 · 射程 1
- 技能：普攻 15% 暴击 ×1.5；**邻位光环：左右相邻格英雄 攻击 +10%**
- 入包方式：demo 通关奖励 / 随机事件「金将挑战」打败获得 / 招募所 0.1% 概率；不入常规卡池

## ✅ 已确认决策汇总（2026-08-18）
1. **布阵点（天机）**：初始 3 点，每通关一层 +1（封顶 6），法宝加成后最高 9；消耗按稀有度 灰1/绿2/蓝3/金4。
2. **自动战斗**：速度序行动一轮=1回合；近战打同列最近 / 远程打同列任意 / 谋略冷却放技；五行克制照常。
3. **格子加成**：每场战斗开始 15 格随机分配（攻击+X% / 倍率×Y / 防御+Z），基础档 攻+10% / 倍率×2 / 防+10%；「买地块」= 后续版本。
4. **稀有度**：村民=灰、12 老英雄=绿、新英雄+白泽=蓝、楚烈=金；普通战候选只出灰绿、boss 战含蓝、金将=招募 0.1% + 事件挑战 + demo 通关奖励。
5. **战时等级**：营帐升级，+（+15%）/ ++（+30%），本局有效，名字后缀 + / ++。
6. **主将可上场布阵**（占用布阵点，阵亡=输）。
7. **demo 地图**：Y 型 —— 雇佣军营帐起点 → 前置 2 节点 → 第3节点帐篷（善恶选择点）→ 善线(好庄园主→善Boss) / 恶线(坏官吏→恶Boss)。
8. **金将楚烈**：攻 22 / 主将血 60 / 邻位光环左右 +10% 攻 / 普攻 15% 暴击 ×1.5。
9. **卦象**：第 3 回合下卦 3 选 1、第 5 回合上卦 3 选 1（主动弹窗）、第 7 回合天命自动合成。
10. **测试场景**：新战斗模式从流寇教学战开始（灰绿英雄）。
