# 九宫八阵 · 天命牌

> 版本 **v3**（主将制 + 卡包 + 爬塔）· 纯静态网页游戏（HTML + CSS + 原生 JavaScript）
> 双击 `index.html` 即可离线运行，无需构建与后端。

## 玩法简介

- **主将制**：开局从 13 名英雄任选 1 名当**主将**——他就是「你」，有血量（被打的就是他，主将死 = 输）；其余英雄变成**招式牌**进卡包。
- **卡包**：主将外 12 名英雄各 4 张 = **48 张封顶**；手牌上限 **10 张**（不可改）；每回合起手 **5 张**，天机 **3/3**（出牌耗 1）。
- **三类招式牌**（与五行脱钩，五行只做克制 ×1.3/×0.7）：
  - **战斗**：发起攻击（多为单体，点怪打出；草间溜为全体，点出即打）
  - **护卫**：获得防御 / 恢复血量（点出即打；闷嘴石为例外，点怪减伤 30% + 回血）
  - **计谋**：能力牌（观星眼 = 天机上限+1 抽 2；冷算子 = 点怪降攻 + 风蚀；**白泽·玄机** = 手牌抽满至 10）
- **操作**：点击手牌 → 卡牌放大 20% + 轻微摆动 → 点击怪物攻击；用完一张回卡包，下回合随机补 5 张。
- **卦象**（每场战斗重新算）：第 3 回合抽下卦 → 第 5 回合抽上卦 → **第 7 回合天命（64 卦）觉醒**。
- **爬塔**：每层「小怪战斗点 → 营帐（回满血+随机 buff）→ 随机事件（buff/debuff）→ 魔王战斗点（胜则开启下一层）」，怪物随层数变强。

## 页面

| 页面 | 内容 |
|---|---|
| 首页 | 马蹄金 / 军粮（体力，每日 5 点）展示；开始战斗（有存档变「继续战斗」）；商店 / 招募所（开发中） |
| 地图 | 顶栏「← 返回（保存回首页）+ 第 N 层 + 📊 统计」；路径倒置展示（魔王战最上 → 事件 → 营帐 → 小怪 → **🏘 王下村（起点）**），线性推进 |
| 战斗 | 顶栏「← 返回（确认丢战斗数据退出）+ 🃏 卡包检视」→ 魔王本体 → 5 魔将（小怪战 2 只）→ 界河（下卦/上卦/天命 三行效果）→ 天机 → 手牌两层（默认上 3 下 2，随张数平均分布）→ 主将天赋及法宝 → 主将头像/血量/防御 → 回合完毕 |
| 奖励 | 战斗胜利后展示战利品（英雄卡包 / 马蹄金 / 军粮 / 法宝，先做样子），结束回地图 |

## 运行

双击 `index.html` 即可。建议使用 Chrome / Edge。

> 修改任何 JS/CSS/图片后，需同步更新 `index.html` 中的 `?v=` 版本号以强制刷新浏览器缓存。

## 目录结构

```
index.html               页面骨架（首页/地图/战斗 + 弹窗）
css/style.css            全局样式（暗金国风 + v3 页面/手牌动画）
js/
├─ data/                 数据（五行/13英雄/八卦/64卦/魔王）
├─ core/                 核心（事件系统/对局状态/存档/回合流转）
├─ systems/              系统（卦象合成/规则引擎/战斗）
├─ render/               渲染（招式卡与主将卡/战场/弹窗）
├─ input/clickController.js  点击出牌（点卡→放大摆动→点怪）
├─ test/selftest.js      规则自检（519 项断言）
└─ main.js               页面路由与流程控制
tools/run-selftest.js    Node 环境自检运行器
tools/smoke-dom.js       DOM 冒烟测试
images/hero/<id>.png     英雄立绘（当前为程序生成占位图）
```

## 自检

- 浏览器内：右侧调试面板 → 「规则自检」标签页。
- Node 命令行：`node tools/run-selftest.js`（519 项断言：五行克制、八卦、64 卦、英雄数据、卡包 48 张、出牌三分类、主将受击/免死、卦象 3/5/7 节奏、胜负判定、层数成长等）。
- DOM 冒烟：`node tools/smoke-dom.js`（首页 → 选将 → 地图 → 战斗 → 回合流转）。
