# 九宫八阵 · 天命牌

> 版本 v2.0（九宫格 + 天机费用 + 魔将对战）· 纯静态网页游戏（HTML + CSS + 原生 JavaScript）
> 双击 `index.html` 即可离线运行，无需构建与后端。

## 玩法简介

- **布阵**：战场为**上 3 下 2 两排共 5 格**（中宫 slot 1 = 上排中间），每回合从 12 英雄牌库随机抽 5 张上阵。
- **天机行动**：每回合 4 点天机，拖一张英雄卡攻击消耗 1 点；攻击过的英雄本回合不可再行动。
- **五行克制**：金→木→土→水→火→金（克制 ×1.3 / 被克 ×0.7），暴击 10%（×1.5），兵种特技 25% 触发。
- **卦象系统**：开局三选一上卦（一局固定）；下卦由九宫格第 1 行前 3 格英雄阴阳爻合成，随阵容每回合重算；64 卦特效 = 上卦规则 + 下卦规则。
- **魔王**：5 魔将（魔焰将为全体攻击）+ 魔王本体「混沌·六爻魔」（100 血，魔将全灭前守护）；魔王本体最上独占一行，魔将上 2 下 3 排列。
- **胜负**：胜 = 5 魔将全灭且本体血量归零；负 = 12 英雄全部退场。

## 运行

双击 `index.html` 即可。建议使用 Chrome / Edge。

> 修改任何 JS/CSS/图片后，需同步更新 `index.html` 与 `cardRenderer.js` 中的 `?v=` 版本号以强制刷新浏览器缓存。

## 自检

- 浏览器内：右侧调试面板 → 「规则自检」标签页。
- Node 命令行：`node tools/run-selftest.js`（514 项断言：五行克制 25、八卦成卦、64 卦完整性、
  伤害公式取整、护盾/复活/持续伤害、魔王守护解锁、战斗集成、回合流转等）。

## 实现说明（对文档的修正/补充）

1. **巽卦爻序**：文档 4.3 将「巽」写作「阴阴阳」与「艮」重复，已按标准卦象修正为「阴阳阳」（☴ 下阴中阳上阳）。
2. **规则数量**：文档称 24 种规则但表格实际列出 25 行（含 jiji/weiji），全部实现。
3. **64 卦特效**：由「下卦规则 + 上卦规则」自动组合推导；同键数值相加，概率类封顶 60%、减伤封顶 70%。
4. **空位成卦**：九宫格第 1 行空缺格按「阳」爻处理，不阻断成卦。
